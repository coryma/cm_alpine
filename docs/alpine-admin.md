# Alpine Admin 操作說明

部署後，內部人員可在 Lightning App Launcher 開啟 `Alpine Admin`。

在 `Products` tab 內，切到 `Alpine Storefront Admin` list view，即可集中管理 Alpine demo 商品。

建議操作方式：

1. 進入商品 record。
2. 在 `Alpine Storefront Controls` 區塊編輯以下欄位。
3. 勾選 `Show on Alpine` 控制是否上架。
4. 用 `Alpine Sort Order` 控制前台排序，數字越小越前面。
5. 用 `Alpine Category`、`Alpine Badge`、`Alpine Short Description` 維護展示文案。

這次交付不包含 Experience Cloud route、前台 LWC、或 Commerce 設定修補。
